# Habit Tracker

A simple and clean personal Habit Tracker built with **Python** and **Streamlit**.

Track your daily habits, mark them as done, view streaks, and see your weekly progress — all in one place.

## Features

- Add new habits
- Mark habits as completed for the day
- Edit and delete habits
- Current streak for each habit
- Today's progress bar
- Last 7 days progress chart
- Data is saved permanently using CSV files

## Tech Stack

- **Python**
- **Streamlit** (for the web interface)
- **Pandas** (for data handling)
